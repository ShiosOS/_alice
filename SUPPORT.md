# Support

## How to get help

| Need | Where |
| --- | --- |
| Bug report | [GitHub Issues](https://github.com/ShiosOS/_alice/issues/new?template=bug_report.yml) |
| Feature idea | [GitHub Issues](https://github.com/ShiosOS/_alice/issues/new?template=feature_request.yml) |
| How to contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Security vulnerability | [SECURITY.md](SECURITY.md) — private advisory only |
| Deploy / ops | [docs/deploy.md](docs/deploy.md), [docs/smoke.md](docs/smoke.md) |

There is no separate support email or Discord for this project yet. Prefer
GitHub issues so discussion stays searchable and reviewable.

## What this project is

_alice is a Wonderland-inspired map for YouTube: Rabbit Holes, intentional
forks, and watch-on-YouTube. Staging and production are documented in the
