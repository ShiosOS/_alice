# Roadmap

Horizon for `_alice` — not a commitment calendar.  
**OpenSpec** owns specs and active changes; this file sequences the big bets.

Mirror as a GitHub Project with columns **Now / Next / Later** (one issue or card per bullet).

## Done (v1 baseline)

- Rabbit Holes (create, list, reopen, rename, delete)
- Expand + Path + Watch on YouTube
- Auth, Postgres, staging → production
- Channel UI (scroll-first, Are.na-inspired)
- Craft standards + automated tests

## Now

- Archive finished OpenSpec changes (`code-craft-standards`, `rabbit-hole-channel-ui`, `ui-wonderland-theme`)
- Channel UI polish (empty states, mobile edge cases, coherence on list/create)
- Expand cost / rate-limit visibility for the operator (ledger already exists)

## Next

- Expand quality (phrase diversity, better fork candidates)
- Soft sharing (read-only link or export — not a social feed)
- Premium expand caps (use existing expand ledger; no full billing yet)

## Later

- Public / social Rabbit Hole gallery
- In-app player
- Visible AI chat
- Full billing / paywall
- Native apps or installable PWA

## How to work an item

1. Move card → **Now**
2. `/opsx-explore` or `/opsx-propose` → OpenSpec change
3. Implement via change tasks → PR → staging → promote
